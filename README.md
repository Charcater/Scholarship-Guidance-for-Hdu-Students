# 杭电奖助学金指南

一个纯静态的杭电本科生历史奖助学金项目分类与个人申请条件初步匹配工具。

- 不依赖服务器、数据库、后台、登录、框架或第三方 CDN。
- 直接双击 `index.html` 即可在本地浏览器使用。
- 所有个人填写数据只在当前页面内计算，不上传、不发送第三方、不写入 localStorage。

> **这不是实时政策查询网站，也不是在线申请系统。** 项目可能已经调整、暂停或取消；匹配结果只代表与历史规则的初步匹配，不代表当前年度具备申请资格。实际申请以杭电及相关设立单位当年度官方通知为准。

## 启动方法

1. 打开文件资源管理器，进入本目录。
2. 双击 `index.html`（推荐 Chrome / Edge）。
3. 无需安装依赖，也无需运行 `npm`、`python -m http.server` 或任何服务器。

如果浏览器对本地脚本有限制，请确认使用本目录内的 `data/projects.js`；项目数据已经作为独立 JS 文件加载，不使用 `fetch()` 读取本地 JSON，因此通常不会遇到 `file://` 的 JSON 跨域问题。

## 页面与功能

- **首页**：网站介绍、历史信息时效声明、数据概况、分类入口、当前重点提示。
- **项目分类**：按国家级、省市级、校级、学院级、社会专项、助学金、勤工助学、学费减免、助学贷款分类；支持关键词搜索和状态筛选。
- **项目详情**：项目名称、类别、层级、历史适用对象、历史条件、历史金额、材料、流程、时间、官方来源、适用年份、最后核实时间和核实状态。
- **个人匹配**：填写年级、学院、专业、GPA、专业排名、综合测评、困难认定、竞赛、学生干部、社会实践、已获奖励等；可全部跳过。
- **使用说明**：匹配规则、数据来源、时效限制、隐私说明和已知缺口。

## 匹配规则（与 `js/matcher.js` 一致）

1. 条件分为硬性、优先、参考三类。
2. 只有用户明确填写为不满足已知硬性条件时，才判“暂不匹配”。
3. 未知/缺失字段一律进入“需要核实”，不自动判为不符合。
4. 优先条件（竞赛、学生干部、社会实践等）不会单独导致“暂不匹配”。
5. 只在项目历史规则明确写出阈值时使用 GPA/排名（例如 2017 版优秀学生奖学金）；不自行推测没有官方依据的资格。
6. 每条结果展示匹配理由、未确认条件和项目历史信息。
7. 结果只代表历史规则初步匹配，不代表当前年度申请资格。

匹配页字段均可跳过；不填写时结果以“需要核实”为主。

## 数据与状态

- 数据来自此前调查的 v0.3 主台账与官方来源索引。
- 项目记录 18 条：已确认存在 8 项，历史项目 1 项，政策框架 3 项，待核实线索 6 项。
- 官方来源 26 条；每个项目尽可能保留多个来源。
- 没有官方证据的类别保留为空。例如“学院级”不展示具体项目，只显示“公开栏目暂未发现可核实的学院专项项目”。
- 缺失字段显示“历史资料暂缺”“官方链接暂缺，需人工核实”或“尚未核实”，不用猜测补全。
- 社会专项 P013-P018 仅有历史通知标题线索，未读正文，不参与自动匹配。

## 官方链接说明

- 项目详情与匹配结果均保留官方来源入口。
- 链接文字使用项目/通知标题或“官方来源”，不直接展示冗长 HTTPS 地址。
- 外部链接在新标签页打开，并带 `rel="noopener noreferrer"`。
- 找不到对应官方页面时显示“官方链接暂缺，需人工核实”，不使用杭电首页替代。
- 已失效或历史版本链接保留记录并标注“历史版本”或“原官方链接可能失效”。

## 已知限制

1. **P005/P006/P008** 的金额与条件主要来自 2017 版学生手册；2025-2026/2026-2027 现行标准可能已调整。
2. **P001-P004** 的 2026-2027 公开通知尚未找到；P003 为 2026-2027 已收集通知。
3. **P007** 是前置资格，不是直接发钱项目；**P010-P012** 仅有政策框架，HDU 细则缺失。
4. **P013-P018** 社会专项只有标题线索，未读正文，不能确认资格、金额或当前是否执行。
5. **电子信息学院**公开栏目暂未发现可核实的学院专项项目；保留空分类，不虚构。
6. 匹配算法只覆盖能结构化的历史条件；复杂条件（如“每学期均获”“一等奖占比”）依赖用户自评，结果仍需人工核实。
7. 网站不提供在线申请、不判断当前年度最终资格、不替代学院/学校审核。

## 隐私

- 不收集身份证号、银行卡号、账号密码等敏感信息。
- 表单字段只在当前页面内参与计算。
- 不使用 Cookie、localStorage、sessionStorage、第三方统计或网络请求。
- 刷新页面后填写内容清空。
